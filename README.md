# AI Evaluation Lab

Practical experiments in AI evaluation, reliability, and response quality.

## About this project

This repository documents hands-on evaluations of AI systems.

The goal is to identify:
- factual errors and hallucinations
- instruction-following failures
- inconsistencies
- reasoning weaknesses
- safety and reliability issues

Each evaluation includes the test scenario, expected behavior,
observed response, analysis, and suggested improvements.
